# Data

Download `Amazon_Unlocked_Mobile.csv` from Kaggle and place it in this folder.

https://www.kaggle.com/datasets/PromptCloudHQ/amazon-reviews-unlocked-mobile-phones

With the Kaggle CLI

```bash
kaggle datasets download -d PromptCloudHQ/amazon-reviews-unlocked-mobile-phones -p data --unzip
```
